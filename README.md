# Vision-Based Automated Conveyor Sorting System

A low-cost automated conveyor prototype integrating computer vision, embedded control, and mechanical design.

## Overview

This project explores automated object sorting using a Python and OpenCV-based vision system connected to an ESP32 microcontroller. The ESP32 controls the conveyor motor and servo-operated sorting gates based on classification commands received from the vision system.

The prototype combines a fabricated conveyor mechanism, 3D-printed mechanical components, embedded electronics, and computer vision in a single automation system.

## Project Objectives

- Develop a functional, low-cost conveyor prototype.
- Implement colour-based and shape-based object classification.
- Integrate computer vision with ESP32 hardware control.
- Operate servo-driven sorting gates based on classification results.
- Document the mechanical design, electrical connections, software, and test results.
